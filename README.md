### 🧑‍💻 About Me

- 🏗️ Software Engineer who **loves system design** — designing services that stay reliable, scalable, and maintainable as they grow.
- 🔧 I enjoy the architecture-level questions: how to **structure services**, **model data**, and **handle load** without things falling apart.
- ⚡ Big on **performance optimization**, **clean code**, and tradeoff-driven decisions over clever hacks.
- 🌱 Always learning — currently going deeper on **distributed systems**, **language internals**, and **observability**.
- 🤖 Exploring **AI solutions** — integrating LLMs and AI agents into backend systems, and using AI tooling to build faster and smarter.
- 💬 Happy to talk architecture, scaling, and the "why" behind design choices anytime.
